## What needs configuration before tomorrow

The user has these on their plate before features need testing:

1. **Google Cloud TTS key** (for the high-quality voices, the whole point of yesterday's last commit)
   - console.cloud.google.com → project → enable "Cloud Text-to-Speech API" → Credentials → API key
   - Web: paste into `bibleapp/web/.env.local` as `GOOGLE_TTS_API_KEY=...`, restart `npm run dev`
   - iOS: Settings tab → "Voice (Listen buttons)" → "Add Google TTS API key"
   - Free tier: 1M chars/month for Chirp3-HD — plenty for personal use
2. **ESV API key** (optional, only if user wants ESV)
   - api.esv.org/account/create-application/ → key → same flow as above with `ESV_API_KEY` / Settings → Translations → "Add ESV API key"

NIV / NKJV need no setup (bolls.life is free, no key).
KJV, BBE, TAM, TEL are bundled — work offline immediately.
